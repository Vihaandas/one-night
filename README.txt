One Night
=========

Open index.html in a modern desktop browser (Chrome, Edge, Firefox, or Safari).
Extract the ZIP first. No installation, local server, or internet connection is
needed to play. All required game code, artwork, and sound are inside the HTML.

Progress is saved in this browser, when browser storage is available. Saves are
not synchronized with other browsers or devices. Moving the file, private
browsing, or clearing browser data may make an earlier save unavailable.

Sound begins after a player interaction. The educational source links open
external websites and need an internet connection. US emergency information
appears in the game; use the appropriate local emergency number.

This download contains the game named above. Other variants are available in
the all-games collection, which includes a launcher.

Hosting: this HTML is self-contained and may be served from any static web
host, including a GitHub Pages repository subfolder.
